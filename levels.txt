# Chess Puzzle - Niveles
# ========================
#
# Piezas: N = caballo blanco (♘)   n = caballo negro (♞)
#         B = alfil blanco (♗)     b = alfil negro (♝)
#         R = torre blanca (♖)     r = torre negra (♜)
#         Q = reina blanca (♕)     q = reina negra (♛)
#         P = peón blanco (♙)      p = peón negro (♟)
# . = vacío   x = muro   f g h i j k ... = casilla meta
#
# Objetivos:
#   f = n             → pieza "n" debe llegar a la casilla "f"
#   f, g, h = n       → pieza(s) "n" deben ocupar f, g y h al mismo tiempo (AND)
#   f > g > h = n     → pieza "n" debe visitar todas las casillas, en cualquier orden
#
# Reglas:
#   · NO se puede capturar NINGUNA pieza.
#   · Piezas deslizantes (R, B, Q) se detienen antes de cualquier pieza.
#   · Muros (x) bloquean el paso y no se pueden pisar.
#   · Peones coronan automáticamente en reina al llegar a la última fila.
#   · Sin turnos: mueves blancas y negras libremente.
#
# Vista desde negras:  # view: black
